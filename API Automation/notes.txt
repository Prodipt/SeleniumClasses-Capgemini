📌 API Basics (Short Notes)
🔹API
    Bridge between client and server
    Used to send request & get response
    Works over HTTP
🔹HTTP Methods
    GET → Fetch data
    POST → Create data
    PUT → Update full data
    PATCH → Update partial data
    DELETE → Remove data
🔹Headers
    Extra info sent with request
    Key-value format
    Examples:
    Content-Type: application/json
    Authorization: Bearer token
🔹Important Status Codes
    200 → OK (success)
    201 → Created
    400 → Bad request
    401 → Unauthorized
    403 → Forbidden
    404 → Not found
    500 → Server error
